Save slots with screenshot thumbnails

GBAGo starts with 4 save state slots, expandable to 12. Every slot shows a screenshot thumbnail of the moment you saved, so you can tell “before the boss” from “after the shop” at a glance and avoid overwriting the wrong one.

Automatic snapshots, also with thumbnails

  • During normal play GBAGo takes a quiet snapshot about every two minutes.
  • The latest 15 snapshots stay available as thumbnails you can jump back to.
  • Auto save when leaving is on by default: close GBAGo and continue exactly where you stopped.
  • In Low Power Mode snapshots happen less often; if the device runs hot, snapshots pause until it cools down.

Recovery Map: all checkpoints for one game on one screen

Each game gets a Recovery Map that gathers the automatic resume point, your save state slots, automatic snapshots and the battery save. Every entry shows a clear status such as Ready to load or Not safe to load, and a Verify Progress check is built in. Safe Continue resumes from your newest checkpoint only when it checks out, so a damaged checkpoint is never loaded silently.

Try it before importing anything: a new library starts with three original Lumi Studio demo cartridges (Lumi Orbit, Pearl Garden and Cloud Atelier), so you can test save slots, snapshots and the Recovery Map right away and delete them whenever you like.

FAQ

What does “visual saves” mean in GBAGo?

Each save state slot and each automatic snapshot shows a screenshot thumbnail of the moment it was made, so you pick a save by what you see instead of by a slot number.

How many visual save slots are there?

4 save state slots to start, expandable to 12. Each slot keeps its own screenshot thumbnail.

What if I forget to save?

During normal play GBAGo takes a quiet automatic snapshot about every two minutes and keeps the latest 15 as thumbnails you can jump back to. It also saves automatically when you leave the app.

Can a broken save be loaded by mistake?

The Recovery Map marks each checkpoint with a status such as Ready to load or Not safe to load, and Safe Continue resumes from your newest checkpoint only when it checks out. A damaged checkpoint is never loaded silently.

Can my saves sync through iCloud?

On iPhone and iPad, when iCloud is enabled, GBAGo syncs save states, thumbnails and .sav battery saves through your private iCloud account. The developer does not receive this data.

Does GBAGo include games?

No. Apart from three original Lumi Studio demo cartridges, it contains no games and does not supply or link to game files. Import only files you created yourself or are authorized to use.
