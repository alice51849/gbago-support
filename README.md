# GBAGo Support Site

Static support / privacy / terms site for **GBAGo — Retro Game Emulator** (iOS, paid, fully on-device).

Live: https://alice51849.github.io/gbago-support/

## Files
- `index.html` — support home + FAQ
- `privacy.html` — privacy policy (zero data collection)
- `terms.html` — terms of use + legal notice (Nintendo non-affiliation, mGBA MPL-2.0 attribution)
- `style.css` — Aurora theme (#FC67AA → #CE5FE8 → #8980F7 → #5A9EFA, gold #E7A95A)
- `i18n.js` — 12-language client-side i18n (en, zh-Hant, zh-Hans, ja, ko, de, fr, es, pt-BR, it, ru, ar/RTL); unknown browser languages fall back to English. Add a language by adding a new object to `I18N` and an entry in `LANG_NAMES` — missing keys fall back to English automatically.

No frameworks, no external resources, no analytics.
